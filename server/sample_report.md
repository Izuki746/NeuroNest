# Clinician Report (SAMPLE, simulated patient)

## Summary
Simulated patient B, 45 years old, left motor cortex stroke affecting the right arm. This is a saved example report used when the Gemini API is unavailable.

## Recovery so far
Arm function has risen steadily over the simulated days, with the fastest gains in the first weeks while the recovery window is open.

## Effort & engagement
Effort was measured from hand movement (depth, speed, hold), not muscle force. Effort stayed high early in sessions and dipped slightly later, a pattern consistent with fatigue.

## Recommended plan & rationale
Excite left dorsal premotor cortex about 80 ms before the movement attempt, two sessions per day. In the simulation this plan outperformed standard rehab and no rehab.

## Forecast with uncertainty
Day-90 arm function is forecast around 78% (range roughly 69-87%). The range narrows as more days are observed.

## Limitations
Simulation only; not medical advice. The model is simplified, patients are simulated, and a real tool would need real patient data and clinical validation across diverse populations.
